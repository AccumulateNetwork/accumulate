🚀 Accumulate SDK Examples

Interactive web interfaces for exploring the Accumulate blockchain

🌐

Network Monitor

Real-time dashboard displaying network status, metrics, and node information

  • Live network statistics
  • Partition metrics & TPS
  • Node information
  • Auto-refresh every 5 seconds
Port 8080
💰

Balance Checker

Check ACME token balances for multiple accounts with formatted display

  • Multi-account support
  • Token issuer statistics
  • Quick account presets
  • Real-time balance updates
Port 8081
📁

Account Explorer

Explore Accumulate accounts and their properties (Web UI coming soon)

  • Account hierarchy exploration
  • Sub-account discovery
  • Property inspection
  • JSON export
CLI Only
📄

Data Reader

Read and display data from Accumulate data accounts (Web UI coming soon)

  • Multiple format support
  • Entry navigation
  • Format auto-detection
  • Hex/Text/JSON display
CLI Only

🚀 Quick Start

To launch all web UIs simultaneously:

./launch_all.sh

Or launch individual applications:

# Network Monitor
cd network_monitor && go run . -web -port 8080

# Balance Checker
cd balance_checker && go run . -web -port 8081

# CLI-only tools (no web UI yet)
cd account_explorer && go run . -url acc://ACME
cd data_reader && go run . -url acc://dn.acme/network
