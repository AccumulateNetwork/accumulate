# Cyclops Deployment: Launch Phase

This document details the steps to properly launch the Cyclops validator node after deployment and configuration.

## Steps

1. **Launch the Validator Node**
   - Execute the appropriate launch command, typically:
     - `accumulated init dual`
   - (Adjust the command as necessary for your deployment scenario.)

2. **Monitor Startup**
   - Check logs for errors or misconfiguration.
   - Ensure the node starts successfully and joins the network as expected.

3. **Post-Launch Validation**
   - Verify that all configuration files remain correct after launch.
   - Confirm the validator is signing blocks and participating in consensus.

---

**Result:**
The Cyclops validator node is running, participating in consensus, and ready for operational monitoring.
