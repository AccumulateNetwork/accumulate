# Cyclops Deployment Scripts

This directory contains all the deployment scripts for the Cyclops validator network.

## Scripts Overview

### Phase Scripts (Sequential Deployment)
- **`phase0-restart-tests.sh`** - Environment setup: removes test directory, recreates it, and copies artifacts
- **`phase1-prep.sh`** - Preparation phase: network initialization and snapshot preparation
- **`phase2-deploy.sh`** - Deployment phase: node configuration and startup preparation
- **`phase3-launch.sh`** - Launch phase: start validator nodes and verify operation
- **`phase4-validate.sh`** - Validation phase: comprehensive network health checks

### Complete Deployment
- **`deploy-cyclops-complete.sh`** - Executes all phases in sequence for full deployment

### Utilities
- **`generate_all_validator_keys.sh`** - Generates validator keys for network participants

## Usage

### Quick Start (Complete Deployment)
```bash
cd /home/paulsnow/go/src/gitlab.com/AccumulateNetwork/accumulate/docs/scripts
./deploy-cyclops-complete.sh
```

### Phase-by-Phase Deployment
```bash
cd /home/paulsnow/go/src/gitlab.com/AccumulateNetwork/accumulate/docs/scripts

# Phase 0: Environment Setup
./phase0-restart-tests.sh

# Phase 1: Preparation
./phase1-prep.sh

# Phase 2: Deployment
./phase2-deploy.sh

# Phase 3: Launch
./phase3-launch.sh

# Phase 4: Validation
./phase4-validate.sh
```

## Requirements

- **Artifacts Directory**: Generated by Phase 1 in `/tmp/cyclops/node/artifacts`
- **Test Environment**: `/tmp/cyclops` (created automatically)
- **Permissions**: Scripts should be executable (`chmod +x *.sh`)

## Script Features

- **Color-coded output** for easy status tracking
- **Progress indicators** showing file operations by name
- **Error handling** with clear failure messages
- **Automatic permission setting** for validator keys and binaries
- **Environment isolation** using `/tmp/cyclops` directory

## Troubleshooting

If scripts fail to execute:
```bash
# Make scripts executable
chmod +x *.sh

# Verify artifacts directory exists
ls -la /tmp/cyclops/node/artifacts

# Check test environment
ls -la /tmp/cyclops
```
